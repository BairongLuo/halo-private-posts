# 文章加密

`文章加密` 是一个 Halo 插件，用来给普通文章加访问密码。

安装后，文章还是按 Halo 原来的方式创建、编辑和发布。需要隐藏的正文会被加密，读者输入访问密码后才能查看。

你可以照常保存草稿、更新文章和发布文章。保存草稿不会把未发布内容暴露给读者；发布之后，读者解锁看到的才会变成新发布的正文。

## 核心能力

- 给 Halo 原生文章设置访问密码，不需要新建另一套文章。
- 文章列表会显示 `已加锁 / 未加锁` 状态。
- 在文章设置里可以启用、取消或更换访问密码。
- 可以填写锁定说明，锁定态前台会把它显示在原摘要的位置。
- 读者在原文章页输入密码后查看正文。
- 页面刷新、切后台或长时间不操作后会重新锁定。
- 忘记访问密码时，可以在后台用平台恢复能力重置。

## 兼容性

- Halo：`>= 2.24.0`
- 加密保存和前台解锁都需要浏览器支持 Web Crypto API，请用 HTTPS 访问 Halo 前台和后台；本地开发可使用 `http://localhost` 或 `http://127.0.0.1`。
- 建议使用最新版 Chrome、Edge、Firefox 或 Safari；部分旧版浏览器和内嵌 WebView 可能不完整支持相关加密能力。

## 安装

1. 从 GitHub Releases 下载插件 JAR。
2. 在 Halo 后台安装并启用插件。

## 使用

1. 打开文章列表或文章编辑页。
2. 进入文章设置，找到“文章加密”。
3. 勾选“启用文章加密”，输入访问密码。
4. 点击 Halo 原生保存。

取消加密时，回到同一个设置区域，取消勾选后保存即可。

锁定说明只影响加密后的前台提示，不会改写 Halo 原生摘要字段。取消加密后，文章会回到普通公开阅读状态。

如果保存或解锁时提示“当前环境不支持 Web Crypto API”，通常是因为当前访问地址是普通 HTTP。请切换到 HTTPS 后重试。

## 忘记密码

如果忘记了某篇文章的访问密码，可以进入后台恢复页面重置：

```text
/console/private-posts
```

恢复只会重置访问密码，不会公开文章正文。

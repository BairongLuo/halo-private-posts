# 文章加密

文章加密是一个 Halo 插件，用于为文章中的指定片段设置访问密码。访客通过密码验证后，页面才显示受保护的内容。

## 系统要求

- Halo 2.24.0 或更高版本

## 安装插件

1. 从 GitHub Releases 下载插件 JAR。
2. 在 Halo 控制台中安装并启用插件。

## 设置受保护内容

1. 在文章编辑器中，使用独占一行的标记包住需要保护的内容：

   ```markdown
   公开内容。

   [hide-password]
   https://download.example.com/secret-file.zip
   [/hide-password]

   继续公开的内容。
   ```

2. 打开文章设置，在 **文章加密** 中输入访问密码。
3. 点击设置窗口底部的 **保存** 或 **发布**。

文章内的所有受保护片段共用同一个访问密码。访问密码最大长度为 256 个字符。

## 更新访问密码

1. 打开文章设置。
2. 在 **文章加密** 中输入新密码。
3. 点击 **保存** 或 **发布**。

现有密码不会回显。输入新密码后，插件会替换原有密码配置。

## 清除访问密码

1. 打开文章设置。
2. 在 **文章加密** 中点击 **清除密码**。
3. 点击 **保存** 或 **发布**。

在保存前点击 **取消清除**，可以撤销清除操作。删除正文标记后，文章也不再显示对应的锁定块。

## 密码存储

插件使用 PBKDF2 生成密码散列，并将配置保存在文章注解中。服务端不保存或回显明文密码。
